# BET - Block'n'Entity Tooltip

A Fabric Minecraft mod that displays the name of the block or entity you're looking at.

## Modrinth

Releases are published at [modrinth.com/mod/block-entity-tooltip](https://modrinth.com/mod/block-entity-tooltip).

## Building

```bash
./gradlew build           # full build + tests
./gradlew runClient       # launch dev client
./gradlew runDatagen      # run data generation
```

Requires Java 25 on the active path for the MC 26.1.x line (Java 21 for the `1.21.11` branch).

## IDE setup

The `.idea/` directory is gitignored — IntelliJ run configurations are generated by Loom, not committed (they contain machine-specific absolute paths).

After cloning, or after editing `gradle.properties`, regenerate the run configs:

```bash
./gradlew ideaSyncTask
```

Equivalent in IntelliJ: Gradle tool window → "Reload All Gradle Projects". This creates/refreshes the `Minecraft Client`, `Minecraft Server`, and `Data Generation` run configurations.

If the IDE-launched client appears to use a stale Minecraft version or stale resources after a `gradle.properties` change, regenerate via the command above — IntelliJ's incremental "Make" build step does not run Loom's `processResources` / `configureClientLaunch`.
